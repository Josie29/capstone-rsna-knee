# Anatomical Planes

The three orthogonal planes every MRI slice is acquired in. A "series" in a study is a stack of 2D slices stepping through the body along one of these planes.

## The three planes

| Plane | Also called | Divides body into | Slice steps... | Analogy |
|---|---|---|---|---|
| **Axial** | Transverse | Top / bottom | Head-to-toe | Slicing a salami |
| **Coronal** | Frontal | Front / back | Front-to-back | Slicing a hamburger bun |
| **Sagittal** | — | Left / right | Ear-to-ear | Slicing a loaf lengthwise, or a book's pages |

Etymology helps them stick: *sagittal* = "arrow" (the path an arrow takes front-to-back splits left from right... the plane runs along that midline); *coronal* = "crown" (a crown sits on the head in this plane).

```
        _O_                    _O_                    _O_
   ----/-|-\----              / | \                  / |#\

       /   \                  /   \                 /  #\
      |     |                |     |               |   #|

   plane is parallel      plane is parallel      plane is parallel
   to the floor           to your screen         to the person's side
```

What each slice looks like (knee):

- **Axial**: a cross-section "donut" — patella in front, femur/tibia shaft behind. You're looking up at the patient from their feet (radiology convention: patient's left appears on image right).
- **Coronal**: the classic "skeleton diagram" view — femur on top, tibia below, joint space between, medial/lateral sides visible.
- **Sagittal**: the "profile" view — you can see the femur curving over the tibia and the patella out front, like a side-on X-ray.

## Why it matters for knee MRI

Each plane is the best (sometimes only good) view for certain structures:

| Plane | Best for |
|---|---|
| **Sagittal** | ACL/PCL (cruciate ligaments run front-to-back, so they lie *within* sagittal slices), meniscal anterior/posterior horns, cartilage |
| **Coronal** | MCL/LCL (collateral ligaments run down the sides), meniscal bodies (middle segment), joint alignment |
| **Axial** | Patellofemoral joint and patellar cartilage, periarticular soft tissue (tendons, muscles, vessels) |

Rule of thumb: a structure is best seen in the plane it *lies in*, not the plane that crosses it. The ACL runs obliquely front-to-back → sagittal. Collaterals run vertically along the sides → coronal.

Radiologists read all three together — the same tear is confirmed by cross-referencing planes. For a model, this means plane type is a strong signal for *which* abnormalities a given series can even show.
