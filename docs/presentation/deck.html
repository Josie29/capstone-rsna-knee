The label problem Kelly · draft

Only 58 of 4,407 studies are labeled. 1.3%.

  • The other 98.7% carry only a free-text radiology report — in ~a dozen languages across ~20 countries
  • The report does not exist at test time — text is a training tool, not an input
  • Mining pipeline: multilingual report → 12 pseudo-labels per study, validated against the 58 gold studies
  • The miner agrees with gold at 0.887 AUC — the ceiling on everything downstream

Appendix · The evaluation metric

ROC AUC, in one picture

  • Each finding gets a probability; ROC sweeps every possible decision threshold and plots true-positive rate vs false-positive rate
  • AUC = area under that curve = the probability a random positive study is ranked above a random negative one — threshold-free, robust to class imbalance
  • 0.5 = no signal (a coin flip ranks pairs correctly half the time); 1.0 = perfect ranking
  • Macro = AUC per finding, all 12 averaged equally — a rare fracture counts as much as a common effusion
  • Our 0.887: the model ranks a random abnormal study above a random normal one ~89% of the time, averaged across findings
